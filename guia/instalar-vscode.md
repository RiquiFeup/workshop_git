# Verificar ou instalar Visual Studio Code

[Voltar ao início](../README.md) · [Roteiro](roteiro.md) · [Slide 16](https://riquifeup.github.io/workshop_git/slides/#slide-16)

## Já está instalado?

Procura **Visual Studio Code** no menu de aplicações e abre-o. Se vires a janela do editor, podes avançar. Neste workshop vais usá-lo para editar `exercicio/README.md`; não precisas de criar conta no VS Code nem de instalar extensões.

## Se precisares de instalar

1. Abre a [página oficial de download do Visual Studio Code](https://code.visualstudio.com/download).
2. Escolhe o teu sistema operativo e segue o instalador. Para passos específicos, usa a documentação oficial para [Windows](https://code.visualstudio.com/docs/setup/windows), [macOS](https://code.visualstudio.com/docs/setup/mac) ou [Linux](https://code.visualstudio.com/docs/setup/linux).
3. Abre o programa e confirma que aparece a janela do editor.

No **Windows**, a instalação por utilizador é suficiente para este exercício. No **macOS**, abre o ficheiro `.dmg` e move a aplicação para **Applications**. Em **Linux**, escolhe o pacote adequado à tua distribuição. Se o computador da sala bloquear a instalação, chama o apoio.

Depois de clonares o teu Fork, abre a pasta `workshop_git` em **File → Open Folder** e, dentro dela, abre `exercicio/README.md`. Guarda a alteração antes de voltar ao terminal.
